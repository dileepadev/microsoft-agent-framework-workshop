# 1. Environment Setup

Set up your local development environment for the workshop.

## Goals

- Install required tools (Python and uv)
- Create and activate a virtual environment
- Install project dependencies
- Prepare local environment variables

## Steps

1. Clone the repository.
2. Install uv.
3. Create and activate a virtual environment.
4. Install dependencies from requirements.txt.
5. Create a .env file with required values.

## Validation

Run the following to verify setup:

```bash
uv --version
python --version
```
