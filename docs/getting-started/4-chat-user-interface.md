# 4. Chat User Interface

Build a chat UI for interacting with your agent.

## Goals

- Connect the agent to a web-based chat frontend
- Stream messages and show responses clearly
- Support iterative testing during workshop development

## Steps

1. Choose a UI framework (Chainlit or Streamlit).
2. Wire the UI to the agent entry point.
3. Test conversational flows end-to-end.
