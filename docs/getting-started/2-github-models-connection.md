# 2. GitHub Models Connection

Connect your project to GitHub Models.

## Goals

- Generate and configure a GitHub token
- Set model-related environment variables
- Verify model access from your application

## Steps

1. Create a GitHub token with the required permissions.
2. Add token and model details in your .env file.
3. Run a simple model test call from the project.

## Example Environment Variables

```env
GITHUB_TOKEN=your_github_token
GITHUB_MODEL=gpt-4o-mini
```
