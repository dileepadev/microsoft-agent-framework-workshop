# 3. Microsoft Agent Framework Agents

Create and configure agents using Microsoft Agent Framework.

## Goals

- Define an agent with instructions and model config
- Organize agent code for maintainability
- Run and validate agent responses

## Steps

1. Create an initial agent module.
2. Add system instructions and model settings.
3. Run the agent locally and validate behavior.
