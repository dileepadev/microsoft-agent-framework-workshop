# 5. Tool Calling

Enable tools so the agent can execute external actions.

## Goals

- Register callable tools
- Define safe tool interfaces and parameters
- Validate tool execution and result handling

## Steps

1. Add one or more workshop tools.
2. Register tools with your agent.
3. Test prompts that require tool execution.
