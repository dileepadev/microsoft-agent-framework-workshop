# 6. MCP Integration

Integrate MCP servers to extend your agent with external capabilities.

## Goals

- Connect an MCP server to the agent runtime
- Use MCP-provided tools from agent conversations
- Verify end-to-end execution with UI and tools

## Steps

1. Configure MCP server connection details.
2. Register MCP capabilities in the agent.
3. Run end-to-end validation from chat UI.

## Outcome

You now have a workshop project with environment setup, model connectivity, agents, UI, tool calling, and MCP integration.
