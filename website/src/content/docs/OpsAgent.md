# OpsAgent

OpsAgent is an AI-powered operations and engineering assistant built using Microsoft Agent Framework, GitHub Models, and MCP servers.

OpsAgent helps developers and cloud engineers troubleshoot issues, retrieve documentation, analyze systems, and automate operational workflows using AI agents, MCP servers, and external tools.

It demonstrates how AI agents can use tools, access external systems, retrieve Microsoft Learn documentation, maintain conversational memory, and orchestrate multi-step workflows for real-world engineering and DevOps scenarios.

## Example User Questions

### Azure / Cloud

> “How do I deploy a container app in Azure?”

OpsAgent:

1. Uses Microsoft Learn MCP
2. Retrieves relevant documentation
3. Summarizes steps
4. Gives CLI examples

### Code Troubleshooting

> "Can you review this old Microsoft Agent Framework Python code with the latest updates and suggest improvements?"

OpsAgent:

1. Analyzes the existing codebase
2. Identifies deprecated APIs and outdated patterns
3. Uses Microsoft Learn MCP to retrieve the latest framework guidance
4. Suggests modern Microsoft Agent Framework implementations
5. Recommends architectural and performance improvements
6. Generates updated code examples
7. Explains migration changes and best practices
